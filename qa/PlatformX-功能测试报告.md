## 一、结论摘要

1. 全部 60 条用例通过，控制台 0 报错、0 个失败请求（含 404），10 个主视图与 6 档视口均无横向溢出。

## 三、缺陷清单（均已修复并回归）

### BUG-01 添加菜单缺少「连接器」入口（中）

- **现象**：输入区 “+” 菜单只有「上传本地文件 / 从资料库引用 / 指定技能 / 切换专家」，无法从任务内进入连接器。
- **冲突需求**：「可以添加文件、技能、专家和连接器」。
- **根因**：`addMenuPopover()` 仅渲染 4 个 `data-id`，switch 分支也没有 connector。
- **修复**：新增「接入连接器」项（带已连接数量），选择后跳转连接器页。
- **验证**：C6 通过，菜单 5 个入口齐全。

### BUG-02 上传资料后列表与侧栏计数不刷新（中）

- **现象**：上传成功后提示「已上传 1 份资料」，但侧栏资料数仍为 10，列表也不出现新文件；若此前停留在某个分类筛选下，新文件（分类「上传」）完全不可见。
- **根因**：`#file-input` 的 change 回调只更新了 `state.docs` 与页面主体，未调用 `renderNav()`；且未重置 `state.docFilter`。
- **修复**：上传后重置筛选为「全部」，刷新侧栏、上下文面板与列表。
- **验证**：F5 通过，10 → 11 份、新文件置顶、计数同步。

### BUG-03 停止任务后状态显示错误（中）

- **现象**：点「停止」后步骤区显示「已停止」，但顶栏仍显示「执行中」；刷新或重进任务后变「已完成」，与「被中断」的事实不符。
- **根因**：停止逻辑只改了 `task.status = 'done'`，没有同步顶栏 `.task-status` 文本；完成态也没有区分「正常完成」和「用户停止」。
- **修复**：新增 `stopped` 标记与 `taskStatusText()`（执行中 / 已停止 / 已完成），停止时同步顶栏，完成写回也走同一函数，避免状态被覆盖。
- **验证**：D6 通过，状态「已停止」，3 个未完成步骤标记为跳过。

### BUG-04 上下文面板不显示当前项目（低）

- **现象**：通过「项目 → 新建任务」绑定项目后，输入区 chip 显示项目名，但右侧上下文面板「工作区」只有模型/资料库/专家/连接器，没有项目。
- **根因**：`renderContext()` 的工作区信息组缺少项目字段。
- **修复**：增加「项目」行，未绑定时显示「未绑定」。
- **验证**：G2 通过，面板与输入区项目一致。

> 说明：首轮执行 31/44，其中 10 项为测试脚本自身的断言问题（比较嵌套文本、异步等待窗口过短、移动端入口选择器取错等），修正断言后复测；另 1 项首轮判定过松（只校验"状态不是执行中"），加严为"必须为已停止"后暴露 BUG-03。

## 四、风险与未覆盖项

| 类别 | 说明 | 建议 |
| --- | --- | --- |
| 真实推理 | 当前回复由 `buildPlan()` 本地模板生成，未接 vLLM / SGLang / Ollama 网关 | 接网关后补一轮"模型真实输出"回归，重点看超时、流式中断、长上下文 |
| 语音识别 | `finishVoice()` 写入的是按模式预设的示例文本，未接 ASR | 接真实 ASR 后测：权限拒绝、无麦克风、噪声、长语音 |
| 并发与长会话 | 未测多任务并行、单任务上百轮对话、200 条任务上限 | 补压力用例，观察 localStorage 体积与渲染耗时 |
| 大文件 | 未实测 100MB 附件与拖拽上传（仅测 4KB 文本与库内引用） | 补拖拽、超大文件、同名覆盖场景 |
| 浏览器 | 仅覆盖 Chrome 155 | 补 Safari / Firefox / Edge，重点看 `backdrop-filter`、`:has()`、滚动条宽度 |
| 无障碍 | 仅覆盖 Esc / ⌘K / ⌘N 快捷键，未做读屏与焦点陷阱测试 | 弹窗补 focus trap 与 aria 标注 |
| 数据安全 | 自定义模型的 API Key 明文存于 localStorage，任何本地脚本可读取 | 生产环境改为后端代理持有密钥，前端只存引用 ID |
| 跨域限制 | 浏览器直连第三方 API 受 CORS 约束，`file://` 打开的页面可能被拦截（已在结果条中提示） | 部署到 http(s) 服务，或统一走自建网关（vLLM / Ollama 开启跨域） |
| 测试连接覆盖面 | 真实链路仅验证到 401 / 404 / 超时分类，未对正常密钥做成功态实测 | 用沙箱密钥补一轮 200 成功态与模型列表解析用例 |
